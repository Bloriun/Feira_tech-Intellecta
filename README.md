# Intellecta

Protótipo visual da rede social escolar Intellecta.

## O que este arquivo entrega

- Estrutura das telas principais
- Visual fiel às referências
- Navegação entre login, cadastro, home, explorar, notificações, chat e perfil
- Componentes estáticos para demonstrar layout e hierarquia visual

## Observação

Este projeto foi revisado para **não usar backend, banco de dados, autenticação real, upload real ou integrações externas**.
Ele serve como base de interface e apresentação visual.

## Como abrir

1. Execute um servidor PHP simples, se desejar, apenas para servir o arquivo `index.php`.
2. Abra `index.php` no navegador.
3. Use o parâmetro `?page=` para alternar entre as telas.
